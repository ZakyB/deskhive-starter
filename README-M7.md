# DeskHive M7 — XML-RPC, XML import and JSON reporting

Branch `m7-xml-json`: M4, M5 and M6 are complete; see
[M7-EXERCISES.md](M7-EXERCISES.md) for the two labs, file locations and checks.

The XML-RPC gateway is a small, **read-only classroom demonstration**, not a
publicly deployable agency integration. XML imports operate on **trusted local
fixtures**; do not use arbitrary uploaded XML in production.
